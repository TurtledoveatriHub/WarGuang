# 地图贴图规范（美术对接）

本目录用于存放**整张世界地图**的手绘贴图。地图不是"每个房间一张图"，而是**两张覆盖整个世界的整图**，
运行时从整图里按房间矩形裁剪显示，因此房间增减或挪位后地图会自动跟随，无需重新对齐。

## 需要的两张贴图

| 文件名 | 用途 | 说明 |
|---|---|---|
| `map_detail.png` | **详情版** | 放大到一定程度后显示，需要能看清房间内部的平台 / 管道 / 门等基本结构 |
| `map_block.png` | **概览版** | 缩小时显示，只保留房间块轮廓（雨世界那种块状地图） |

两张图必须：

1. **尺寸完全一致**（同一画布大小）
2. **原点锚点完全一致**（同一世界坐标对应同一张图上的同一点）
3. 背景透明，只画有内容的区域

## 尺寸怎么定

世界坐标 → 贴图像素的比例由 `Assets/Configs/RoomLayoutData.tres` 的 `map_texture_scale` 决定，
默认 `0.1`，即：

```
贴图像素 = 世界像素 × 0.1
```

贴图覆盖的世界范围由 `Assets/Configs/RoomLayoutData.tres` 里的房间布局决定
（`room_positions` + `room_bounds_rects`）。**先把房间摆放定下来，再按包围盒裁出画布尺寸作画。**

推荐流程：

1. 打开 `Scenes/Tools/WorldLayout.tscn`，用「① 扫描房间边界」「③ 记录槽位位置到数据」把布局定稿
2. 用「校验布局一致性」确认没有缺位置 / 缺尺寸 / 矩形重叠
3. 按定稿后的包围盒 × `map_texture_scale` 得到画布尺寸，开始手绘两张整图

## 房间之间的联通通道

- 通道建议**画在房间矩形内部**（跨房间的通道也尽量贴着边界内侧），这样未探索房间的通道不会露出。
- 如果某条通道必须画到房间矩形之外，就在 `RoomLayoutData.tres` 的 `map_region_rects` 里
  给该房间单独指定一个更大的区域矩形（键为 `room_id`，值为相对房间根节点的 `Rect2`）。

## 未探索房间怎么处理

运行时按房间裁剪：**只有已绘制的房间**才会从整图上取图显示。所以：

- 未走过的房间不会出现在地图上
- 通向未探索房间的通道，只要画在那个未探索房间的区域内，也会一起隐藏

## 缺图时的表现

贴图缺失时，游戏内会回退为**纯色块 + 房间名**，便于先验证逻辑。
`MapManager.get_missing_map_textures()` 会返回当前缺失的文件名清单。
